# VibeRadio — онлайн-радио для Android

Современный плеер на Kotlin + Jetpack Compose + Media3 (ExoPlayer).

## Возможности
- 📻 Радиостанции России, США, Южной Кореи и Германии (живой каталог Radio Browser, ~120 популярных станций на страну) + поиск по всему миру
- ❤️ Избранное, автопереключение на следующую станцию при ошибке, таймер сна
- 🔒 Играет в фоне, при свёрнутом приложении и заблокированном экране; управление из шторки, с экрана блокировки и с Bluetooth-гарнитуры
- 🎛️ 12 эффектов звука: эхо, пещера, стадион, робот, монстр, детский голос, бурундук, пришелец, телефон, под водой, мега-бас
- 💃 Танцующие персонажи, реагирующие на бит: шотландский вислоухий кот, белый крыс, Дикамик, таракан, девочка с русыми волосами, круговой эквалайзер

## Как собрать APK через GitHub
1. Создайте новый репозиторий на GitHub.
2. Загрузите в него **содержимое** этой папки (чтобы `settings.gradle.kts` и папка `.github` были в корне репозитория).
   Через сайт: «Add file → Upload files» (папку `.github` удобнее загрузить через GitHub Desktop или `git push`).
3. Откройте вкладку **Actions** → workflow «Build APK» запустится сам (или нажмите «Run workflow»).
4. Через ~5–8 минут откройте запуск → внизу раздел **Artifacts** → скачайте `VibeRadio-apk` (zip с файлом `app-debug.apk`).
5. Установите APK на телефон (разрешите установку из неизвестных источников).

Минимальная версия Android — 7.0.
