# Оставшиеся ограничения

1. **APK не собран и не установлен на устройство в рамках этой работы** (нет доступа к Android SDK). Сборка — через GitHub Actions
   по инструкции `02_СБОРКА_APK_ЧЕРЕЗ_GITHUB.md`; первый запуск сценария может потребовать правок, если окружение GitHub изменилось.
2. **Нет проверки на реальных устройствах**: системный диалог сохранения/открытия файлов Android проверен только на уровне кода;
   если он не сработает на конкретной прошивке, используйте запасной способ — текстовый код профиля через буфер обмена.
3. **Тестовая подпись**: при каждой сборке на GitHub создаётся новый отладочный ключ, поэтому обновление поверх старой версии
   невозможно — перед переустановкой экспортируйте профили.
4. **Подсказки**: у 2631 задания подсказка сформирована автоматически из объяснения (часть слов скрыта); в 30 заданиях
   валидатор отметил, что такая подсказка частично раскрывает ответ.
5. **Литературное чтение**: произведения не воспроизводятся (авторское право) — задания проверяют знание содержания,
   героев и авторов; читать сами тексты нужно по учебнику или книге. Задания писались по памяти о сюжетах: перед массовым
   использованием желательна вычитка учителем, особенно по малоизвестным рассказам 3–4 классов.
6. **Озвучка** — только английские слова и фразы (синтезатор eSpeak NG, звучит роботизированно). Русские тексты не озвучены.
7. **Издания учебников**: программа составлена по изданиям «Просвещения» 2023–2024 гг.; в других годах порядок тем может отличаться.
8. Графика — векторная, нарисованная кодом (без фотографий): это гарантирует чистоту прав, но стиль проще, чем у коммерческих игр.

Итог: игра функционально завершена (все предметы и темы 2–4 классов заполнены, 5839 заданий, все проверки пройдены),
но статус — **промежуточный до первой успешной сборки APK и проверки на устройстве**.
