# Сборка APK через GitHub (без установки Android Studio)

1. Зарегистрируйтесь на https://github.com и создайте **новый репозиторий** (можно приватный).
2. Загрузите в него **всё содержимое архива**, сохраняя структуру папок. Обязательно должна попасть скрытая папка
   `.github/workflows/android.yml`. Проще всего:
   ```
   git init && git add . && git commit -m "Острова Знаний"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
   git push -u origin main
   ```
   (Через веб-интерфейс «Add file → Upload files» скрытые папки иногда не загружаются — тогда создайте файл
   `.github/workflows/android.yml` вручную через «Add file → Create new file» и вставьте содержимое.)
3. Откройте вкладку **Actions**. Сборка запустится сама после загрузки; вручную — **Build Android APK → Run workflow**.
4. Сборка идёт 8–15 минут. Шаги: проверка банка заданий → автотесты → экспорт APK.
5. Откройте завершённый запуск → внизу раздел **Artifacts** → скачайте `ostrova-znaniy-apk` (zip с APK внутри).
6. Перекиньте APK на телефон/планшет и установите (Android попросит разрешить установку из этого источника).

## О подписи
APK подписывается **тестовым отладочным ключом**, который создаётся заново при каждой сборке на сервере GitHub.
Такой APK подходит только для установки на свои устройства. Личный ключ разработчика в архив не входит.
Важно: из-за нового ключа при каждой сборке Android не даст установить новую версию поверх старой —
сначала сделайте **экспорт профилей** в родительском разделе, удалите старую версию, установите новую и импортируйте профили.

Для публикации в магазине создайте собственный ключ (`keytool -genkeypair ...`), храните его вне репозитория
и передайте в сборку через *Settings → Secrets* (переменные `GODOT_ANDROID_KEYSTORE_RELEASE_*`), заменив `--export-debug` на `--export-release`.

## Требования к устройству
Android 7.0+ (API 24), arm64 или armeabi-v7a, OpenGL ES 3.0. Подходит для телефонов и планшетов; ориентация — альбомная.
