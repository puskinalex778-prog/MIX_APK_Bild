## 2. Автотесты Godot — `project/tests/unit_tests.tscn`
Результат: **67 проверок пройдено, 0 провалено.** Проверено:
* сохранение: атомарная запись, появление резервной копии, удаление временного файла; **повреждённый основной файл → восстановление из .bak**; чужой формат не принимается;
* профили: разные стабильные id, ответы одного ребёнка не попадают другому, банки классов не смешиваются;
* экспорт/импорт: PIN и код восстановления не попадают в файл; предпросмотр; **изменённый файл отклоняется по контрольной сумме**; битый/пустой/более новый формат отклоняется; **неудачный импорт ничего не меняет**; импорт копией и заменой; **другие профили не меняются**; неизвестные поля и пути вычищаются; код через буфер обмена;
* PIN: проверка, формат, блокировка после 5 ошибок (верный PIN во время блокировки не принимается), код восстановления, смена PIN;
* статистика: точность считается только по первому знакомству с заданием (повторы не завышают), повторение отдельно, рекомендации без слова «диагноз»;
* **правильный ответ каждого из 5839 заданий принимается механизмом проверки**;
* нормализация ответов (регистр, ё/е, пробелы в числах, формат времени), перемешивание порядка заданий;
* мастерская умножения: план дня ≥10 фактов, все 8 режимов дают ≥10 заданий, статистика по факту;
* отрисовка каждого вида задания;
* прокрутка пальцем: свайп, начатый на кнопке, прокручивает список, и кнопка при этом не нажимается; короткое касание по-прежнему нажимает кнопку.

Во время тестов найдены и исправлены 2 ошибки: пустой план дня в мастерской умножения для нового профиля;
сохранение прогресса только в конце урока (теперь — после каждого ответа).
