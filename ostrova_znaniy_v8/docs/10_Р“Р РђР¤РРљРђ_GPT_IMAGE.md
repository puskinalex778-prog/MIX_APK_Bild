# Как заменить графику на картинки из GPT Image (ChatGPT)

Сейчас вся графика рисуется кодом. Игра умеет подхватывать готовые картинки: если в папке
`project/assets/art/` лежит файл с нужным именем, он показывается вместо рисованного кодом варианта.
Если файла нет, остаётся вариант, нарисованный кодом. Поэтому картинки можно добавлять по одной и в любом порядке.

## 1. Какие картинки нужны

### Персонажи — `project/assets/art/characters/` (PNG с ПРОЗРАЧНЫМ фоном)
Размер 1024×1024. Персонаж стоит в полный рост, ноги касаются нижнего края, вокруг почти нет пустого места,
смотрит на зрителя или чуть вправо. Без теней на полу (тень игра рисует сама) и без текста.

| Файл | Кто это |
|---|---|
| `lumik.png` | Лумик, главный герой: светлячок — круглая тёмно-серая головка со светлой мордочкой, большие добрые глаза, усики с жёлтыми шариками, оранжевое тельце, прозрачные голубые крылышки, большое светящееся жёлтое брюшко-фонарик, короткие ручки и ножки |
| `cloud.png` | Чихуля: пушистое белое облачко с ручками, немного простуженное, розовый носик |
| `robot.png` | Робот Цифрон (математика): голубой квадратный робот, экран-лицо с зелёными глазами, антенна с лампочкой, цифры на груди |
| `fox.png` | Лиса Буквица (русский язык): рыжая лисичка в шарфике, держит перо или книгу с буквами |
| `raccoon.png` | Енот Компас (окружающий мир): енот-путешественник с рюкзаком и компасом |
| `cat.png` | Кошка Молли (английский): серая кошечка с британским флажком на шарфе |
| `owl.png` | Сова Страничка (литературное чтение): коричневая сова в круглых очках с книгой |
| `kid_a.png` … `kid_f.png` | Аватары детей — шесть разных ребят 7–10 лет. В коде заданы цвета: a — короткие каштановые волосы, синяя футболка; b — чёрные торчащие волосы, зелёная; c — рыжие кудри, оранжевая; d — рыжие хвостики, розовая; e — чёрные волосы в пучке, жёлтая; f — длинные светло-каштановые, фиолетовая |

### Фоны — `project/assets/art/bg/` (PNG или JPG, 1920×1080, альбомная ориентация)
| Файл | Где используется |
|---|---|
| `sky.png` | карта островов, экраны предметов и уроков: голубое небо, облака, солнце справа вверху, море в нижней трети |
| `night.png` | родительский раздел, настройки, достижения: спокойное ночное небо, луна, звёзды, тёмное море |
| `calm.png` | перерывы и гимнастика для глаз: сиреневый закат, мягкие облака, спокойное море |

На фонах не должно быть островов, персонажей и текста: поверх них игра рисует карточки и кнопки.
Центральную часть делайте спокойной, без мелких деталей.

### Острова — `project/assets/art/islands/` (PNG с прозрачным фоном, 1024×768)
Парящий в воздухе остров: травяная площадка сверху, каменная скала снизу сужается к низу, верх площадки — примерно на 40% высоты картинки.
| Файл | Тема острова |
|---|---|
| `math.png` | Остров Чисел: башенка с часами, кубики с цифрами |
| `rus.png` | Остров Слов: домик-библиотека, буквы-флажки |
| `world.png` | Зелёный остров: деревья, цветы, маленький пруд, глобус-флюгер |
| `eng.png` | Порт Hello: маяк, причал, красный автобус-игрушка |
| `read.png` | Остров Сказок: сказочный теремок, раскрытая книга |

## 2. Готовые подсказки (промпты) для GPT Image

Одинаковый стиль задаёт общая часть — добавляйте её в каждый запрос:

> **Стиль:** яркая детская 2D-иллюстрация для обучающей игры, мягкие округлые формы, чистые цвета, аккуратный тёмный контур,
> мягкие тени, дружелюбное выражение лица, без текста, без логотипов, без водяных знаков. Не похоже на персонажей известных мультфильмов.

Примеры запросов:

* Персонаж: `Нарисуй персонажа для детской игры: Лумик — весёлый светлячок: круглая головка, большие добрые глаза, усики с шариками, прозрачные крылышки, светящееся жёлтое брюшко-фонарик, короткие ручки и ножки, улыбается. Полный рост, стоит прямо, ноги у нижнего края. Прозрачный фон, PNG, 1024×1024. [Стиль]`
* Фон: `Нарисуй фон для детской игры, 1920×1080: голубое небо с пушистыми облаками, солнце в правом верхнем углу, спокойное море в нижней трети, вдали силуэты гор. Без островов, без персонажей, без текста. Центр спокойный, без мелких деталей. [Стиль]`
* Остров: `Нарисуй парящий в воздухе маленький остров для детской игры: сверху травяная площадка с башенкой с часами и кубиками с цифрами, снизу каменная скала, сужающаяся книзу. Вид сбоку, чуть сверху. Прозрачный фон, PNG, 1024×768. [Стиль]`

Аватары детей удобнее рисовать одним запросом («шесть разных детей в одном стиле»), а затем просить
каждого отдельно: «нарисуй третьего ребёнка отдельно, полный рост, прозрачный фон».

Если фон получился не прозрачным, попросите «сделай фон прозрачным» или удалите его любым сервисом удаления фона.
Сохраняйте результат именно в PNG (в JPG прозрачность пропадает).

## 3. Как заменить

1. Переименуйте картинки точно как в таблицах выше: имя маленькими латинскими буквами, расширение `.png` (для фонов можно `.jpg`).
2. Положите их в папки:
   ```
   project/assets/art/characters/lumik.png
   project/assets/art/bg/sky.png
   project/assets/art/islands/math.png
   ...
   ```
   (Папок `characters`, `bg` и `islands` пока нет — создайте их сами.)
3. **Проверка на компьютере:** откройте проект в Godot 4.6.2. Он сам импортирует новые файлы. Нажмите F5.
4. **Новый APK:** загрузите новые файлы в репозиторий на GitHub (Add file → Upload files, в ту же папку) — сборка в
   Actions запустится сама. Готовый APK заберите в разделе Artifacts.
5. Чтобы вернуть графику, нарисованную кодом, удалите файл картинки.

## 4. Что нужно знать
* Персонажи, нарисованные кодом, анимируются по частям: моргают, машут руками, шагают ногами. Готовая картинка
  анимируется целиком: игра её покачивает, наклоняет, растягивает при прыжке радости и отражает при ходьбе в другую
  сторону, но моргать и махать отдельной рукой картинка не может. Если анимация по частям важнее, заменяйте только
  фоны и острова.
* Большие картинки увеличивают размер APK: для персонажа достаточно 1024 px, для фона — 1920×1080 в JPG.
* Права: картинки, созданные вами в ChatGPT, можно использовать в своём проекте (по условиям OpenAI права на
  результат принадлежат пользователю). Не просите нарисовать «как в мультфильме N» — персонажи должны быть
  оригинальными. Впишите новые картинки в `docs/07_ПРАВА_НА_РЕСУРСЫ.md`.
