# Как открыть и запустить проект

1. Скачайте **Godot 4.6.2 (стандартная версия, не .NET)** с https://godotengine.org/download/archive/4.6.2-stable/
2. Распакуйте архив проекта. Запустите Godot → **Import** → выберите файл `project/project.godot` → **Import & Edit**.
3. При первом открытии Godot импортирует ресурсы (шрифты, звуки) — это 1–2 минуты.
4. Нажмите **F5** (или ▶ вверху справа). Игра откроется в окне 1280×720.

## Что где лежит
| Папка | Содержимое |
|---|---|
| `project/scripts/core` | логика: профили, сохранения, банк заданий, проверка ответов, PIN, статистика, тренажёр умножения, перерывы, звук |
| `project/scripts/screens` | экраны игры |
| `project/scripts/tasks` | 10 механик заданий |
| `project/scripts/art` | персонажи и декорации (рисуются кодом, анимация по частям) |
| `project/data/content` | банк заданий: 15 JSON-файлов (класс × предмет) |
| `project/data/curriculum` | реестр программы и покрытие пунктов оглавлений |
| `project/assets` | шрифты, музыка, звуки, английская озвучка |
| `project/tests` | автотесты |
| `tools/` | реестр программы, генераторы и валидатор заданий, генераторы звука и документации |

## Пересборка банка заданий (Python 3.9+)
```
cd tools/content
python3 build_content.py        # собирает project/data/content/*.json
python3 validate_content.py     # проверка: должно быть ERRORS: 0
python3 ../make_docs.py         # пересчитать таблицы документации
```
Авторские задания — в `tools/content/dsl/*.txt` (синтаксис описан в начале `build_content.py`),
генерируемые (математика, русский, английский) — в `tools/content/*_g?.py`.

## Автотесты
```
godot --headless --path project res://tests/unit_tests.tscn    # 67 проверок логики, всего банка и прокрутки
godot --headless --path project res://tests/check_all.tscn     # компиляция всех скриптов
xvfb-run godot --path project --rendering-driver opengl3 res://tests/shots.tscn   # скриншоты всех экранов в user://shots
```
Тесты пишут в пользовательскую папку Godot (`user://`) — запускайте их не на устройстве ребёнка.
