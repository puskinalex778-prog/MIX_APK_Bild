# Острова Знаний — обучающая игра для 2–4 классов (Godot 4.6.2 → Android)

Математика, русский язык, окружающий мир, английский язык (Spotlight) и литературное чтение по учебникам «Школа России».
**560 тем, 5839 заданий** (не меньше 10 в каждой теме), 11 механик, сюжет с персонажами, мастерская таблицы умножения
(8 режимов, статистика по каждому факту), перерывы с гимнастикой для глаз, несколько детских профилей, родительский
кабинет с PIN, статистикой, журналом ошибок, рекомендациями и экспортом/импортом профилей.

**Статус: промежуточный** — всё содержание и проверки готовы, но APK ещё не собирался и не проверялся на устройстве
(см. `docs/09_ОГРАНИЧЕНИЯ.md`).
